# ops/ — Dev/Ops-агенти наземної станції

Автоматизує те, що ми робили руками: діагностику «нема відео», мережу на RK,
перезапуск приймача/sender'а, провіжн. Два шари:
- **`ops/*.sh`** — детерміновані цеглинки (можна запускати руками);
- **`.claude/agents/stream-doctor.md`** — Claude-агент, що оркеструє ці цеглинки.

> Запускати з машини, яка **має мережевий доступ до плат** (термінальний Claude
> на ноуті). Ця хмарна сесія плат не бачить.

## Швидкий старт
```sh
# (один раз) ключі, щоб без пароля:
ops/setup_keys.sh

# діагностика «нема відео» → причина + фікс:
ops/diagnose.sh                 # або --full для повних звітів

# точкові фікси:
ops/fix_rk_ip.sh                # адресу 192.168.1.2 на порт із кабелем
ops/fix_restart.sh rk           # перезапуск приймача на землі
ops/fix_restart.sh rv           # перезапуск sender на борту

# окремі звіти стану:
ops/rv_check.sh                 # борт
ops/rk_check.sh                 # земля
```

## Через Claude-агента
У термінальному Claude:
> Відео на наземці нема — поклич агента stream-doctor, хай знайде причину й полагодить.

Агент сам проганяє `diagnose.sh`, застосовує потрібний фікс і перевіряє результат.

## Параметри (env з дефолтами)
| Змінна | Дефолт | Що |
|---|---|---|
| `RV_HOST` | 192.168.1.10 | борт RV1106 (eth0) |
| `RK_HOST` | 192.168.0.162 | земля RK (керування, WiFi) |
| `BEAM_RX` | 192.168.1.21 | наземний Beam |
| `GCS_IP` | 192.168.1.2 | адреса приймача на землі |
| `VIDEO_PORT` | 5700 | RTP/UDP відео |
| `RV_USER`/`RK_USER` | root / armsom | логіни |

Приклад із іншими адресами:
```sh
RK_HOST=192.168.1.2 BEAM_RX=192.168.1.21 ops/diagnose.sh
```

## Що робить дерево `diagnose.sh`
`RK доступна? → порт із кабелем / IP на ньому / без конфлікту → Beam RX пінгується
→ є пакети udp/5700? → (так) приймач/синк : (ні) keepalive? → борт: RTSP живий?`
і на кожному зриві — причина + конкретна команда-фікс.

## Дорожня карта (наступні агенти)
- `board-bringup` — провіжн плати з нуля (ллє `delivery/`, мережа, служба, перевірка).
- `deploy` — крос-збірка бінарів RV + заливка + рестарт.
- `ground-watchdog` — демон на RK, що сам кличе діагностику/фікс при збої.
