# Пакет відтворення: тепловізійний тракт RV1106 → Beam → RK3588

Три самодостатні папки — щоб відтворити систему з нуля без проблем. Кожна має
свій README з покроковою інструкцією (SDK → збірка → заливка → команди).

```
Seek 640 → RV1106 (H.265, RTSP, апскейл 1280×1024) → Beam TX ))) радіо ((( Beam RX → RK3588 → HDMI
```

## Папки
| Папка | Про що | Головне всередині |
|---|---|---|
| **RV1106/** | борт: камера → H.265 → RTSP | `src/rtsp_sender.cpp`, `Makefile.rtsp.prebuilt`, `init.d/S99thermal`, README (SDK, збірка, заливка) |
| **RK3588/** | земля: приймач Beam → HDMI | `setup.sh`, `thermal_receiver.sh`, `thermal-receiver.service`, `99-beam.conf`, README |
| **UPSCALE/** | апскейл 640×512→1280×1024 | пояснення RGA-апскейлу в sender'і + `upscale-frame.sh`, README |

## Швидкий старт (порядок)
1. **RV1106/** — зібрати `rv1106_rtsp` (потрібен Luckfox SDK), залити на плату,
   поставити `S99thermal`, режим `rtsp`, IP `192.168.1.10`. Перевірити RTSP без Beam.
2. **Beam** — у TX вписати Cam IP `192.168.1.10` (`rtsp://192.168.1.10:554/stream=0`);
   на модемах max power + Dynamic power.
3. **RK3588/** — `bash setup.sh`, підібрати робочий синк (xvimagesink/glimagesink),
   `systemctl restart thermal-receiver` → відео на HDMI.

## Мережа (пам'ятка)
| Пристрій | IP |
|---|---|
| RV1106 камера | 192.168.1.10 (+192.168.50.2 сервіс) |
| Beam TX / RX | 192.168.1.11 / 192.168.1.21 |
| RK3588 приймач | 192.168.1.2 (на порту з кабелем) |
| RK3588 керування | 192.168.0.162 (WiFi) |

Потік на землі: **RTP/UDP H.265, payload 96, на `192.168.1.2:5700`**.

## Три правила, без яких «не заводиться»
1. Приймати через **ffmpeg** (він шле RTCP — Beam від цього стрімить), не голим gst.
2. **Безперервний keepalive-пінг** на `192.168.1.21` (інакше Beam глушить потік).
3. Адреса `192.168.1.2` — **лише на порту з кабелем**; синк — **xvimagesink/glimagesink**
   (не rkximagesink для софт-декоду).
